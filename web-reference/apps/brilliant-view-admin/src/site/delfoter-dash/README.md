# Delfoter Dash

A local, deterministic, ground-surfing platform game in the admin arcade. No API or new dependencies are required. Route: `/delfoter-arcade/dash`.

-   `engine.ts`: movement, fixed 120Hz substeps, forgiving body hitbox, buffered jumps, coyote time, platform landings, gaps, pads, air rings, shell collection and completion. Holding jump chains ordinary landings; air rings require a fresh press. Restarts create a fresh state.
-   `levels.ts`: course registry, colors, speed, BPM, music and authored variable-length phrases. Add a phrase to `PHRASES` or a course to `DASH_LEVELS`. Course length and shell arcs are derived from the phrase list. Sections advance by their actual duration instead of a fixed 16-beat slot, keeping the runs around 23–28 seconds with tighter transitions and fewer repeated patterns. All ten courses have a tested clearable route, including required rings, pillar landings and Phase gates. Custom ring and pillar phrases use physical distances so their requirements remain consistent at different tempos.
-   `worlds.ts`: world themes and progression. Neon Coast has five levels; Frostbyte Fjord has five more and unlocks only when every Neon Coast completion record is true. Both the menu and start action enforce this. Existing saved completion records are retained. Previewing a locked world does not start it.
-   `surfer.ts`: original canvas character and hover-surfboard art, shared with the arcade card. The decorative tail, cap and board do not enlarge the body hitbox.
-   `renderer.ts` / `DashCanvas.tsx`: parallax skyline, `fjordScenery.ts` auroras and glaciers, beat glow, neon obstacles, spinning saws, rings, water wake and bursts. Canvas scales for device pixel ratio and screen shape. Reduced-motion settings disable decorative rotation, pulsation and moving particles while preserving essential gameplay movement.
-   `useDash.ts`: React lifecycle, animation loop, input state, records, pause and audio. Leaving the tab pauses the run; returning requires Resume. Keyboard modifiers retain normal browser shortcuts. Unmount releases both animation loops and audio resources.
-   `audio.ts`: native looping music and synthesized jump, pickup, boost, landing, crash and finish cues. Drop in starts audio synchronously from a user gesture, respecting the arcade's saved mute preference. Music pauses with the game and stops on navigation.
-   `records.ts`: validated local best completion percentage and shell count for each course. Storage being unavailable does not block play.
-   `DashMenu.tsx` / `DelfoterDashPage.tsx` / `dash.css`: course picker, live HUD, pause/wipeout/finish panels, mute and fullscreen controls.

The soundtracks use distinct melodies, chord progressions, bass patterns, drum rhythms and lead instruments; they are not speed-adjusted copies. The ten original action tracks are generated by `scripts/generate-dash-soundtracks.mjs`. Regenerate with:

```sh
node apps/brilliant-view-admin/scripts/generate-dash-soundtracks.mjs
```

Controls: Space / Up / W / click / tap to jump; hold to chain jumps; press again near a glowing air ring to boost. Rings first appear in Neon Coast level 3 and sit over trenches too wide for a normal jump. Pillar bridges appear in level 4. Level 5 adds a continuous double-ring trench: jump, tap ring 1, then tap the higher ring 2 while still airborne. Missing either boost fails the crossing. Numbered ring labels also appear on the later Frostbyte Fjord chains. Frostbyte Fjord introduces Shift / X or the on-screen Phase button: 0.32 seconds of laser-gate immunity, with a 1.4-second recharge. Phase does not protect against spikes, saws or falling. P or Escape pauses, R restarts. The touch canvas captures pointer releases and cancellations so holding cannot get stuck.

Run `pnpm --filter brilliant-view-admin test src/site/delfoter-dash src/site/arcade-lobby` and `pnpm --filter brilliant-view-admin typecheck` when changing physics or audio. Human playtesting remains necessary for pacing and difficulty.
